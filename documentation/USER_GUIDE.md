# XII OS 1.0 (Genesis) — Complete User Guide & Manual

ยินดีต้อนรับสู่ **XII OS 1.0 (Genesis)** ระบบปฏิบัติการเดสก์ท็อป Linux x86-64 ยุคใหม่ที่ออกแบบมาเพื่อความสวยงาม ความเร็ว และความฉลาด

---

## 1. การเริ่มต้นใช้งาน (Getting Started)

### คีย์ลัดหลักของระบบ (Essential Keybindings)

| คีย์ลัด | การทำงาน |
|---|---|
| `Super + Space` | เปิด XII Launcher (ค้นหาโปรแกรมทันที) |
| `Super + Enter` | เปิด XII Terminal |
| `Super + E` | เปิด XII Files (โปรแกรมจัดการไฟล์) |
| `Super + ,` | เปิด XII Settings (ศูนย์การตั้งค่าระบบ) |
| `Super + A` | เปิด XII AI Assistant (ผู้ช่วยอัจฉริยะ) |
| `Super + Q` | ปิดหน้าต่างปัจจุบัน |
| `Super + F` | ขยายหน้าต่างเต็มจอ (Fullscreen toggle) |
| `Super + V` | สลับโหมด Floating / Tiling |
| `Super + 1–9` | สลับ Virtual Workspace |
| `Super + Ctrl + 1` | เปลี่ยนเป็น **XII Lite Mode** |
| `Super + Ctrl + 2` | เปลี่ยนเป็น **XII Standard Mode** |
| `Super + Ctrl + 3` | เปลี่ยนเป็น **XII Performance Mode** |
| `PrintScreen` | บันทึกภาพหน้าจอ (Screenshot) |

## 2. โหมดการทำงาน 3 ระดับ (XII 3-Tier Modes)

XII OS ออกแบบมาให้ปรับตัวเข้ากับสภาพแวดล้อมฮาร์ดแวร์ของคุณได้ทันที:

1. **XII Lite (ประหยัดแรมสูงสุด):**
   - เหมาะสำหรับแล็ปท็อปประหยัดแบตเตอรี่ หรือเครื่องที่มี RAM 2GB–4GB
   - ใช้ Idle RAM ต่ำกว่า 350 MB
   - ปิดเอฟเฟกต์เบลอหนัก และลดแอนิเมชันลงเหลือ 150ms

2. **XII Standard (โหมดมาตรฐานสมดุล):**
   - สวยงาม นุ่มนวล ตอบสนองฉับไว
   - ใช้งาน Glassmorphism ระดับ 16px และแอนิเมชัน 250ms
   - ค่าเริ่มต้นสำหรับคอมพิวเตอร์ทั่วไป

3. **XII Performance (ประสิทธิภาพสูงสุด):**
   - เร่งประสิทธิภาพ GPU acceleration เต็มรูปแบบ
   - แสดงผล Glassmorphism ระดับ 24px พร้อมแสงนีออนเรืองแสง (Glow effects)
   - CPU Scheduler ปรับเข้าสู่โหมด `performance` สำหรับงานหนักและเกมมิ่ง

## 3. การจัดการซอฟต์แวร์ (Package Management)

XII OS รองรับ 3 รูปแบบแพ็กเกจหลักอย่างไร้รอยต่อ:

### ใช้งานผ่าน Terminal (`xii` CLI)
```bash
# อัปเดตรายการซอฟต์แวร์
xii update

# ติดตั้งโปรแกรม (.deb หรือ Flatpak อัตโนมัติ)
xii install code

# ค้นหาโปรแกรม
xii search vlc

# ถอนการติดตั้งโปรแกรม
xii remove vlc

# แสดงข้อมูลโปรแกรม
xii info firefox
```

### ใช้งานผ่านหน้าต่างกราฟิก (XII Store)
- เปิด **XII Store** จากแถบ Dock หรือ Launcher เพื่อดาวน์โหลดโปรแกรมที่มีการตรวจสอบความปลอดภัยดิจิทัล (XII Verified)

---

## 4. ระบบความปลอดภัย (Security & Integrity)

- **XII Security Center:** ตรวจสอบคะแนนความปลอดภัยของระบบ (0–100)
- **Stateful Firewall (nftables):** นโยบาย Least-Privilege ปิดกั้นการเชื่อมต่อขาเข้าที่ไม่ได้รับอนุญาตโดยอัตโนมัติ
- **AppArmor Application Sandbox:** แยก sandbox โปรแกรมที่ติดตั้งไม่ให้เข้าถึงไฟล์สำคัญในระบบ
- **Integrity Monitor:** ตรวจสอบความถูกต้องของไฟล์ระบบด้วยฐานข้อมูล SHA-256

---

## 5. การอัปเดตและกู้คืนระบบ (Update & Recovery)

- **ระบบ Snapshot อัตโนมัติ:** ทุกครั้งที่มีการอัปเดตระบบใหญ่ ระบบจะสร้าง Snapshot สำรองไว้ก่อนเสมอ
- **การ Rollback 1-Click:** หากการอัปเดตมีปัญหา สามารถเปิดโปรแกรม `XII Updater` แล้วเลือกย้อนกลับไปยังจุดคืนค่าที่ต้องการได้ทันที
- **XII Recovery Console:** ในกรณีที่ระบบบูตไม่ขึ้น ให้เลือกเมนู `XII OS (Recovery Mode)` ในหน้าจอ GRUB เพื่อเปิดเมนูซ่อมแซมระบบฉุกเฉิน, ตรวจเช็กดิสก์ (fsck), ซ่อมแซม GRUB หรือย้อนคืน Snapshot

---

## 6. ผู้ช่วยอัจฉริยะ (XII AI Assistant)

กด `Super + A` เพื่อเปิดผู้ช่วยอัจฉริยะ:
- ถามข้อมูลระบบ: *"ใครกิน RAM มากที่สุด"*, *"ทำไม Wi-Fi ใช้ไม่ได้"*, *"สถานะระบบ"*
- สั่งการปรับโหมด: *"ปรับโหมดประหยัดพลังงาน"*
- **Least-Privilege Gate:** เมื่อมีคำสั่งที่อาจส่งผลกระทบต่อระบบ เช่น ล้างแคชระบบ หรือติดตั้งโปรแกรม ระบบ AI จะหยุดและแสดงปุ่มยืนยันสิทธิ์จากคุณก่อนเสมอ เพื่อป้องกันการสั่งการผิดพลาด
